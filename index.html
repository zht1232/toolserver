隐私与部署

大多数工具在浏览器本地运行；AI 水印修补是用户主动选择的服务器功能。

安全设计
  • 本地处理：音乐解密、常规图片转换压缩和文本工具在浏览器内存完成，服务器不接收这些文件。
  • AI 修补：只有点击“运行 AI 并下载结果”后，所选图片和遮罩才会经 HTTPS 发送给本站服务器，限制大小、串行推理且只在内存处理，不写入磁盘。
  • 可离线：除歌词检索外，所有工具断网可用。
  • 零依赖：不使用任何第三方 JS 库或 CDN，全部为原生代码，可直接审计 assets/js/。
  • 服务器职责：静态文件、酷狗密钥表分片、歌词中转，以及保存用户主动提交的文字反馈。
  • 对外请求清单：歌词检索（歌名/歌手名）、密钥表分片、用户主动提交的反馈，以及用户主动选择的 AI 图片修补。反馈存于站点目录之外。
部署

方式 A · 自带服务器（推荐，仅需 Python 3 标准库）：

cd toolbox
python3 server.py 8000

首次启动会把 assets/kugou_key.xz（94 KB）解压为 70 MB 密钥表，供新版酷狗文件按需分片读取，无需用户下载整表。

方式 B · 纯静态托管：整个目录交给 Nginx / Caddy / IIS 即可。歌词自动回退 LRCLIB；超 64 MiB 的酷狗新版文件会提示按需加载 12 MB 压缩密钥表。

server {
  listen 80;
  root /var/www/toolbox;
}

以 file:// 双击打开时：NCM 等本地工具可用；需读取掩码表的酷狗解密与联网检索不可用。

算法来源与声明

NCM 解密与 ncmdump / unlock-music 实现一致；KGM / KWM / QMC / XM 解密算法移植自 unlock-music（MIT）与 ghtz08/kugou-kgm-decoder（密钥表来自后者）。两个上游项目的官方测试向量均已通过。

本项目仅供个人对已合法获得的音频进行格式转换与备份，请尊重音乐版权。
